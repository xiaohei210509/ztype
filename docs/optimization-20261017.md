# ztype 0.1.3 本地优化验证

日期：2026-10-17。应用版本：0.1.3，build 4。

## 本轮变更

1. 推理上下文按实际 token 预算缩减。保留可信模板、最近前文和紧随光标的
   后文，最多检查六个窗口；字面用户文本始终按普通 tokens 编码。词尾
   healing 保留，语言策略来自原始上下文。无法装入时返回明确预算错误，
   不把这个分支混同为候选过滤。AX 快照和 UTF-16 接受基线不裁剪。
2. 辅助功能监听记录注册结果，区分成功、明确不支持和暂时失败。成功项
   不重复注册；不支持项不重试。输入和焦点相关事件可触发最多三次恢复，
   成功或监听关闭即停止，切换应用使旧任务失效。它不是常驻轮询，也不按
   软件名称选择分支。恢复通知仍走已有候选一致性检查。
3. `Hi,`、`你好，` 等短边界前缀允许预测；单字母、纯空白及换行尾不触发。
   中文或混合候选采用系统词边界逐词接受，保留原始字符和空格。
4. 界面延迟改为输入调度到候选发布，包含去抖、捕获、模型加载、推理和
   最后校验；P95 只统计最近 100 次展示。推理时间作为独立值保留。
   发布不是显示器实际呈现帧的测量。

连续 Tab 消费原候选、候选耗尽不生成、真实编辑使旧候选失效，这些要求
没有改变。天气、数字、日期、原因及时间承诺仍允许开放续写。

## 自动化验证

完整 Swift Testing 回归通过。覆盖长中文和混合上下文、角色标记、emoji
组合字、词尾 healing、无法装入的单个超长字素、取消时不继续生成、通知
注册分类、有上限恢复、应用切换及关闭取消，以及中英文连续 Tab 的原候选
和 UTF-16 回执保持。

普通测试未开启三个可选的 Chrome/Pages 实机读取用例；模拟通知恢复及
接受夹具不是第三方应用全流程实测。

本机 CLT 环境复现命令：

```bash
env DEVELOPER_DIR=/Library/Developer/CommandLineTools swift test \
  --disable-xctest --scratch-path "$HOME/Library/Caches/ztype/Build" \
  -Xswiftc -load-plugin-library \
  -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing/libTestingMacros.dylib
```

## 真实模型样本

模型仍是独立来源的 Qwen3-1.7B-Q8_0，未替换权重或推理后端。测试仅使用
源码内的合成文本，不读取个人文稿。原始结果保存在本机
`Benchmarks/optimization-20261017.json`，不加入公开源码。

```bash
env DEVELOPER_DIR=/Library/Developer/CommandLineTools \
  python3 script/benchmark.py --output Benchmarks/optimization-20261017.json
```

该次 28 条样本记录：

| 项目 | 观测值 |
| --- | --- |
| 模型冷加载 | 约 1,470 ms |
| 请求推理 P50 | 约 132 ms |
| 请求推理 P95 | 约 1,590 ms |
| 超预算压力样例 | 裁剪至 1,812 prompt tokens，约 1,622 ms，返回非空候选 |
| 空闲推理进程 CPU | 第二个 5 秒区间样本约 0.5% |

这些是单机单次观测，无本轮前的同条件对照，不能用于宣称相对提速。推理
延迟不包含 UI 去抖或模型冷加载；CPU 区间采样不等于 GPU/整机能耗或续航。

长重复背景样例仍可能返回空续写，最终不展示；已有英文残词也可能
没有可用候选。超预算样例返回不代表语义必然正确。候选展示条数不是准确率，
也不是应用兼容率。

## 保留边界

- 第三方组合输入法仍保守暂停；中文逐词接受不意味着已解决全局 IME
  组词状态判断。内置编辑器仍通过 marked text 区分组词和已提交内容。
- 没有读取屏幕、其他窗口或剪贴板来扩展模型上下文，也未新增输入历史
  收集、个性化训练或云端请求。
- 未声称全应用兼容、长上下文即时返回或候选准确率提高。当前优先修复
  已确认的预算与监听生命周期问题。
- Cotypist 报告作为架构对照。本轮问题可由 ztype 源码和测试直接定位，
  因而没有新增 REA 会话，也未复用对方实现或资产。
- 上述数据来自本机开发版本验证；公开发行包单独进行 release 构建，
  使用临时签名，不复用本机开发证书。发行内容与安装限制见
  [0.1.3 发布说明](releases/v0.1.3.md)。
