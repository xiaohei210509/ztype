# ztype 0.1.0

**免费、开源的 Cotypist 平替，专为 Mac 打造。**

ztype 是独立项目，与 Cotypist 无关联。源码采用 MIT 许可证。

## 下载

下载本页的 `ztype-0.1.0-arm64.dmg`，并使用配套的
`ztype-0.1.0-arm64.dmg.sha256` 核对文件。

- 适用：Apple Silicon Mac，macOS 14 或更高版本。
- 包含：编译好的应用、llama.cpp 推理运行时及 Qwen3 1.7B 本地模型。
- 安装后不需要另外下载模型，也不需要配置云端 API。
- 内置模型使安装包较大；不是 Intel 或 Windows 安装包。

## 安装

1. 打开 DMG，将 `ztype.app` 拖入 `Applications`。
2. 从“应用程序”目录打开已安装的 ztype，不要从 DMG 里直接运行。
3. 开启跨应用补全，按系统提示授予“辅助功能”和“输入监控”权限。
4. 在 ztype 设置中确认“Tab 接管”显示“可用”。

**此初始公开发行包使用临时签名，尚未完成 Apple 公证。**
首次打开时 macOS 可能阻止启动。先核对下载来源和 SHA-256；只有确认
信任此应用时，才按系统“隐私与安全性”中的提示允许打开。不要关闭
Gatekeeper。更新临时签名版本可能需要重新授权。

## 主要功能

- 当前输入框上下文驱动的灰色行内候选。
- 本机 Metal 推理，无云端补全请求。
- Tab 逐词接受，Option+Tab 接受整个剩余候选。
- 连续按 Tab 保留同一条候选；自己输入新文字后才重新预测。
- 菜单栏后台运行、内置试写区、按需加载及空闲卸载模型。
- 通过编辑器公开的辅助功能能力读取和验证，不按软件名字逐个特判。
- 剪贴板临时保管、插入回执验证，以及输入改变后的取消处理。

## 已知边界

各编辑器的辅助功能实现不同，不保证兼容所有软件。跨应用的组合输入法
保守暂停，完整中文输入法兼容性尚未建立。模型候选是续写预测，不是
事实核查结果。剪贴板会被短暂使用，强制退出无法保证恢复。
