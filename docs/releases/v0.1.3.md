# ztype 0.1.3

**免费、开源的 Cotypist 平替，专为 Mac 打造。**

ztype 是独立项目，与 Cotypist 无关联。源码采用 MIT 许可证。
此版本汇总自公开版 0.1.0 以来的改进，应用版本为 0.1.3（build 4）。

## 本次更新

- 扩大共享辅助功能读取能力：布局型、自定义编辑器、文字标记及经过
  上下文验证的子文本光标回退，不按应用名称添加专用补丁。
- 常规读取失败时，仅对明确支持且可写的属性请求增强辅助功能，再读取焦点；
  不修改系统权限。通知注册区分不支持与暂时失败，真实事件后最多恢复三次，
  不增加常驻轮询。
- 长草稿按实际 token 预算保留光标附近的前后文，避免上下文超限时静默
  返回空候选；用于验证插入的原始文本快照保持不变。
- 支持 `Hi,`、`你好，` 等短边界前缀。中文及中英混合候选采用系统词边界
  逐词接受，连续 Tab 仍消费原候选，实际新输入才重新生成。
- 设置中可复制最近一次读取失败的诊断，不包含正文、网址、窗口标题、
  剪贴板内容或本机路径，也不会自动上传。
- 界面显示输入调度到候选发布的耗时及最近 100 次展示的 P95，推理耗时
  单独保留；增加预算、监听恢复、光标解析与连续 Tab 的回归覆盖。

## 下载与安装

下载 `ztype-0.1.3-arm64.dmg`，并使用
`ztype-0.1.3-arm64.dmg.sha256` 核对文件。

- 仅适用 Apple Silicon Mac，macOS 14 或更高版本。
- 包含编译好的应用、llama.cpp 运行时及 Qwen3 1.7B 本地模型。
- 安装后无需另行下载模型或配置云端 API；内置模型使安装包较大。

1. 退出正在运行的 ztype，打开 DMG，将 `ztype.app` 拖入 `Applications`。
2. 从“应用程序”目录打开已安装的 ztype，不要从 DMG 中运行或授权。
3. 开启跨应用补全，按系统提示授予“辅助功能”和“输入监控”权限。
4. 在 ztype 设置中确认“Tab 接管”显示“可用”。

**公开发行包使用临时签名，尚未完成 Apple 公证。**
首次启动可能被 macOS 阻止；更新后也可能需要重新授权。请先核对下载
来源与 SHA-256，只有确认信任时才按系统“隐私与安全性”提示允许打开。
不要关闭 Gatekeeper 或重置系统权限数据库。

## 验证与边界

Swift 回归测试、打包辅助测试及发行包签名和结构校验通过。
可选 Chrome/Pages 实机读取用例未在本次发布回归中启用；读取夹具、
模拟接受及权限检查不代表所有编辑器的灰字显示与 Tab 接受全流程均已验证。

跨应用行为仍取决于编辑器的辅助功能支持，不保证全应用兼容。组合输入法
在跨应用模式下仍保守暂停；中文分词不意味着已解决第三方输入法组词状态。
候选是开放续写预测，不是事实验证；天气、数字、日期等仍可预测。

补全仅在本机推理。跨应用接受会短暂租用剪贴板，确认后恢复；
新复制内容不覆盖，强制退出无法保证恢复。暂无自动更新或 Intel 版本。
性能样本及局限见仓库中的 `docs/optimization-20261017.md`。
